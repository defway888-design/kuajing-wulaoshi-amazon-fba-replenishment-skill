# 跨境吴老师 亚马逊 FBA 备货 Skill

本 Skill 分两阶段完成亚马逊 FBA 备货：先在上传的 XLSX 或可编辑在线表格中创建、更新本周参数，供运营填写；再读取本周参数、重新拉取 LingXing MCP 数据，生成单文件离线 HTML 备货 BI 看板。

仓库：[kuajing-wulaoshi-amazon-fba-replenishment-skill](https://github.com/defway888-design/kuajing-wulaoshi-amazon-fba-replenishment-skill)。当前为公开仓库，安装时无需提交 GitHub 用户名或接受私有仓库邀请。

## 适用场景

- 本周在上传的空白 XLSX 或在线表格中创建、更新运营参数表，供运营填写。
- 参数填写完成后，另行生成本周单文件离线备货 BI 看板；不做旧表迁移。

## 运行前准备

- 在运行者自己的环境中配置 LingXing MCP。Skill 每次运行先检查连接和所需工具；未通过时会先提示配置、重新授权或修复连接，通过后才要求输入表格。首次输入二选一：上传完全空白的 `.xlsx` 工作簿，或提供完全空白、可编辑的在线表格直接链接；无需同时提供。不要在对话中发送密码或密钥。
- 选择在线表格时，还需当前环境具备对应平台的可读写连接。成功绑定后独立运行复用本用户绑定。选择上传工作簿时不需要腾讯文档连接；若环境不能跨次保存文件，下次运行重新上传上次更新后的 XLSX，而不是重新上传空白文件。

## 首次安装

本仓库为**公开仓库**，无需提交 GitHub 用户名或接受私有仓库邀请；不要在对话中提供密码或访问令牌。

点击下方代码块的复制按钮，将整段指令发送给 Codex：

```text
请从 https://github.com/defway888-design/kuajing-wulaoshi-amazon-fba-replenishment-skill 安装跨境吴老师 亚马逊 FBA 备货 Skill。
```

安装后按当前平台提示刷新或重新加载 Skill；只有当前客户端未识别新 Skill 时才重启。

## 启动方式

第一阶段——生成或更新本周参数表：

```text
使用跨境吴老师亚马逊 FBA 备货 Skill，生成或更新本周参数表。
```

运营填写完成后，另行启动第二阶段——生成本周看板：

```text
使用跨境吴老师亚马逊 FBA 备货 Skill，生成本周备货 BI 看板。
```

两阶段必须分别触发；也可按 Skill 提示管理当前用户可复用的参数表来源。

## 执行结果与失败边界

- 第一阶段只更新本周参数表：在线路径返回链接，上传路径返回写入后的 XLSX；不自动执行第二阶段。
- 第二阶段重新拉取 Listing、FBA 库存及 30／14／7 天销量，通过参数和数据校验后交付一个可下载的单文件离线 HTML 看板；上传路径还交付写回快照和运行记录后的同一工作簿 XLSX。核心数据缺失、匹配不确定或模板校验失败时停止。

## 使用边界与安全

本仓库不包含 LingXing 登录信息、在线表格绑定、上传的运营工作簿、运营真实数据或生成的正式看板。请勿将凭证、访问令牌或客户数据提交到此公开仓库。

- 不要把密码、Token、API Key、个人连接配置或真实客户数据提交到本仓库；数据连接使用运行者自己的环境。
